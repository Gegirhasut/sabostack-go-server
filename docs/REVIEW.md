## Шестой раунд (13.11.2026)

Ревью коммита `ef7ea08`, оценка 9.7/10. Ошибок не найдено. Подробнее всего ревьюер
разобрал срочную очередь, потому что она меняет порядок записи. Для одного матча
гарантия сохраняется: в очереди максимум одна задача на матч, всегда с последними
данными, и пишет её одна горутина шарда. Поэтому поздний периодический снапшот не может
затереть финальный или «воскресить» удалённый матч. Меняется только порядок между
разными матчами. Ревьюер прямо сказал, что дальше смысл имеет реальная нагрузка, а не
ещё один раунд ревью.

| # | Замечание | Решение |
|---|---|---|
| 1 | После записи через один список id остаётся в другом. | Оставлено как есть. Лишней записи нет, только проверка map при проходе. Таких id не больше, чем срочных записей. |
| 2 | Если срочных записей больше пачки и они идут непрерывно, периодические снапшоты шарда откладываются без конца. | Пока в очереди есть периодические записи, срочные занимают не больше половины пачки. Место, которое периодические не заняли, возвращается срочным. Тест `TestReviewAwaitedWritesDoNotStarveRoutineOnes`: после наплыва из 50 срочных записей первая пачка без ограничения целиком срочная, с ограничением половина в ней периодические. |
